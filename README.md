One line, 128 characters, in which a robot vacuum explains why it missed a spot:

> Log 214: the crumb under the table survived 41 passes, so I reclassified it as furniture. It has seniority. I respect seniority.

`main.py` (pure Python standard library, no third-party packages) writes that
line to `/output/entry.txt` and prints it. The output is deterministic: a
fixed string, no clock, no randomness, no network.

## Run it

```sh
python3 main.py
```
